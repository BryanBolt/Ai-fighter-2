Roguelite : les boutons n'apparaissent qu'avec les pouvoirs

Début de run : joystick, Poing, Pied, Saut / esquive, rien d'autre. Chaque bouton apparaît (rebond + un mot) quand le pouvoir qui le justifie est gagné : Spécial avec un daemon, Garde avec le premier pouvoir, Saisie et Course avec le deuxième, Super avec un super ou une forme. Avec plusieurs pouvoirs (4 au plus), le bouton Spécial montre celui qui PARTIRA. Pas de tuto : un glyphe, un mot.

Captures du vrai moteur (variante 1 intégrée par défaut)

16 variantes de la sélection des pouvoirs

Maquettes de l'idée. Seule la variante 1 est dans le jeu ; dis laquelle garder, ou à refaire.

1. Pastille active + éventail (dans le jeu)

Le bouton Spécial montre le glyphe du pouvoir ACTIF, sa jauge de recharge monte dans l'icône ; les autres pouvoirs sont de petites pastilles autour.

Lancer / changer : Appui = le pouvoir actif. Il saute au suivant prêt après un lancer. Glisser le doigt = pouvoir de la direction. Tab / direction + Spécial au clavier et à la manette.

Sur le héros : Le glyphe du pouvoir qui partira flotte au-dessus de la tête, avec son mot.

2. Anneau segmenté

Un arc coloré par pouvoir autour du bouton ; l'arc épais est l'actif.

Lancer / changer : Appui = actif ; toucher un arc le choisit.

Sur le héros : Aucun.

3. Roue au maintien

Maintenir ouvre une roue de 3-4 icônes.

Lancer / changer : Relâcher sur une icône la lance.

Sur le héros : Aucun.

4. Pile de cartes

Les pouvoirs sont des cartes empilées, la première est active.

Lancer / changer : Glisser la carte vers le haut la range dessous.

Sur le héros : Aucun.

5. Colonne latérale

Pastilles alignées à côté du bouton, l'actif est entouré.

Lancer / changer : Toucher une pastille la choisit.

Sur le héros : Aucun.

6. Daemons porteurs

Les daemons flottent autour du héros ; celui qui est devant est l'actif.

Lancer / changer : Toucher un daemon le met devant.

Sur le héros : Tout est sur le héros : aucun bouton en plus.

7. Glyphe sur la tête seul

Le bouton garde la teinte de l'élément ; le glyphe est au-dessus du héros.

Lancer / changer : Appui = actif ; Tab change.

Sur le héros : Glyphe et mot sur la tête.

8. Aura au sol

Un cercle teinté sous les pieds donne l'élément actif.

Lancer / changer : Appui = actif.

Sur le héros : Aura colorée sous le héros.

9. Quatre directions

Une flèche colorée par direction autour du bouton.

Lancer / changer : Glisser dans la direction = ce pouvoir (comme avant + Spécial).

Sur le héros : Aucun.

10. Bouton en quadrants

Le bouton est coupé en 4 quarts de couleur.

Lancer / changer : Toucher un quart le lance.

Sur le héros : Aucun.

11. Jauge liquide seule

Un seul pouvoir à la fois, la jauge monte dans l'icône.

Lancer / changer : Appui = lance.

Sur le héros : Aucun.

12. Carrousel

Trois icônes au bord du bouton, l'actif au milieu.

Lancer / changer : Glisser à gauche / droite fait défiler.

Sur le héros : Aucun.

13. Cartes dans la salle

Choix d'un pouvoir : trois cartes illustrées (icône + un mot).

Lancer / changer : Toucher une carte la prend.

Sur le héros : Le pouvoir pris apparaît sur le héros.

14. Bracelet à gemmes

Des gemmes de couleur au poignet du héros, une par pouvoir.

Lancer / changer : Appui = la gemme allumée.

Sur le héros : Bracelet visible sur le héros.

15. Fantôme du suivant

Le pouvoir suivant apparaît en halo derrière l'actif.

Lancer / changer : Double-tap = passer au suivant.

Sur le héros : Aucun.

16. Cristaux en orbite

Un cristal par pouvoir tourne autour du héros ; l'allumé est prêt.

Lancer / changer : Appui = le cristal le plus proche.

Sur le héros : Cristaux autour du héros.
