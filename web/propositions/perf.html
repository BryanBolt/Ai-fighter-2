4. Notifications push

Le code est pret et desactive tant que les cles manquent. A renseigner dans Render (Environment) : VAPID_PUBLIC, VAPID_PRIVATE (generees une fois avec npx web-push generate-vapid-keys), VAPID_SUBJECT (mailto:...). Aucune cle n'est dans le depot. Test : ouvrir /push/key.
